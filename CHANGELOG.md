# CycleCell upgrade changelog

## Public-test revision — 12 November 2026

Based on the public main-branch repository (original root site had Sell, Buyer and Admin flows with USD sample prices, certificates and browser-local records):

- Replaces misleading blanket secure-wipe/certificate language with **device-specific proposed handling** and evidence-led TrustTrack.
- Replaces USD sample numbers with **illustrative BDT** rules, clearly distinguished from ML or live market prices.
- Preserves the project’s original three-sided model (seller, parts/material buyer, operator), adds a separate TrustTrack explorer and prototype feedback page.
- Provides simulated end-to-end status progression and an unmistakably marked **DEMO ONLY** printable report.
- Prevents acceptance of swollen-battery devices via the normal sample-quote flow.
- Allows sample bulk orders and local sample inventory management.
- Removes unnecessary personal contact/serial-number collection from a site with no backend.
- Adds anonymous, local-only feedback capture and CSV export for supervised tests.
- Adds zero-dependency unit tests, static deployment documentation, and a production security roadmap.
- Uses standard HTML, CSS and JavaScript with relative assets; no build step.

**Intentionally not implemented:** actual device erasure, secure server-side identity or accounts, shared real-time database, payments, verified certificate, true audit logs, logistics, production quote ML, or real recyclable inventory.
